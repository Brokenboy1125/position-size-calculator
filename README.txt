POSITION SIZE CALCULATOR — iPhone setup

The app is a responsive web app. To install it on the iPhone Home Screen, it must be hosted at an HTTPS address.

EASIEST METHOD (GitHub Pages):
1. On a computer or phone, sign in/create an account at https://github.com
2. Create a new public repository named position-size-calculator.
3. Upload all files in this ZIP (index.html, manifest.json, sw.js, icon-192.png, icon-512.png).
4. In repository Settings → Pages, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish the site. The URL will look like https://YOUR-USERNAME.github.io/position-size-calculator/
6. Open that HTTPS URL in Safari on the iPhone.
7. Tap Share → Add to Home Screen → enable “Open as Web App” if shown → Add.

The calculator uses a manually entered pip size and pip value. Confirm these with your broker, especially for gold, crosses, and contracts where the account currency differs from USD. The calculations exclude trading costs and slippage.
